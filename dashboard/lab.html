TRAINING ONLY / TARGET SELECTION DIAGNOSTICS

When does the constraint change a target?

At a logged nonterminal successor, the treatment selects the highest online Q among actions recorded at that successor. Evaluation remains unrestricted. Diagnostics compare unrestricted and constrained choices on the treatment’s same weights; they do not compare the two trained networks.

      Which experiences help the learner?

      Both conditions use the same Double DQN target procedure, network, all four actions, and update budget. One samples every training state. The other samples unique states encountered during random collection on the same layouts. The support and sampling distribution change together; this is offline learning, with the movement rule visible initially.

        CONTROLLED OFFLINE COMPARISON / FULL ACTION COVERAGE

        Same experience. Two ways to form an answer.

        Both networks see the same fixed bank of states and all four action transitions. Only their target procedure changes: exact optimal returns, or one-step Double DQN estimates. The movement rule stays visible. This isolates target learning under rich offline coverage; it does not establish online RL competence.

        Exact Q*Double DQN
        1. Same inputsStates, all actions, transitions
        2. Two target proceduresExact Q* / reward + next estimate
        3. Same learning setupNetwork, loss, batches, budget
        4. Their own rolloutsNew fresh layouts; no oracle actions

        Bootstrapping means building today’s target from the network’s estimate of what happens next. Exact targets stay fixed; bootstrapped targets move as the network learns. Both conditions use privileged state coverage, with no online collection or added memory.

          OFFLINE SUPERVISION / PRIVILEGED EXACT TARGETS

          Fit the values. Test the behavior.

          An exact solver supplies the optimal discounted return for all four actions at each training state. The existing network fits those answers offline. This is supervised learning with privileged targets; it does not establish learning from interaction or RL competence.

          Same networkFour exact targets
          1. Visible stateWalls, goal, position, clock
          2. Exact action targetsQ* for ↑ ↓ ← →
          3. Same networkFit the supplied values
          4. Its own rolloutChoose actions on fresh layouts

          Exact answers supervise training. During a fresh rollout, the network chooses its own actions; the solver supplies no actions to it. Small value errors can still flip which direction ranks first.
