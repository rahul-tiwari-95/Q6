# No Way Home: interpretation and implementation errata

2026-09-06. Original files under `no_way_home/results/` and the locked preregistrations are retained as historical records. This note supersedes their stronger interpretation; it does not rewrite what was run.

1. **The historical beta trend is built into the score/outcome.** Raw count is always at least unique count, so increasing its unique-count weight lowers the score. Before the shift, mitigation cannot change sickness/messages. "Any pre-shift mitigation" is therefore a threshold-crossing event on the same message history, nonincreasing in beta by construction. The observed grid `[.82, .82, .68, 0, 0]` is reproducible; beta=.75 is a successful tested point in one generator, not a universal knee or an emergent mechanism.
2. **Paired seeds require paired analysis.** The original JT implementation pooled observations across seeds despite reusing the same seeds across policies. `jonckheere_terpstra_test(..., paired=True)` now permutes policy labels within each seed. The [separate reanalysis](../../experiments/provenance/beta-paired-reanalysis/RESULTS.md) retains J=18650 and Monte Carlo p=.0001. Correcting the sampling design does not erase the observed contrast; p=.0001 is the simulation resolution floor. Independent-sample mode remains available for genuinely independent data.
3. **Equal thresholds do not isolate the value of lineage information.** Lower counts also make a policy more conservative. The new [release pilot](provenance-results.md) calibrates raw, unique and bounded-decay controllers with equal candidate budgets, scores whole-task shortfall, and includes never-mitigate. The original bounded-decay omission is now addressed in this separate exploratory experiment, not backdated into the original confirmatory result.
4. **The learner was given deduplication.** It learned action preferences over raw-count and already-deduplicated unique-count features. It did not learn lineage extraction from raw messages. Frozen evaluation from one training sequence does not establish online adaptation or robust learning superiority. A floored learning rate becomes constant after20 visits; it is not a convergence guarantee. Missing wealth is one possible explanation for underperformance, not an isolated cause.
5. **The last learning transition was dropped.** The learner updated on the next action call, which never arrived for a run's last step. `world.run()` now supports optional start/end lifecycle hooks. The learner consumes the final reward once with no terminal bootstrap and clears transition bookkeeping between episodic runs. This changes training semantics: historical learner numbers should not be presented as results of the corrected implementation. Its driver now writes a separate artifact by default.
6. **Seeded message histories now reproduce.** Message origin IDs formerly came from a process-global counter. They now start at zero in each `MessageLog`; report/forward lineage relationships are preserved while full histories become independent of preceding runs. IDs are scoped to a run; artifact identity includes scenario, policy and seed.
7. **Scope terminology.** The implementation has four locality sickness counts, shared resources and one collective binary action. It is an aggregate stochastic-control lab, not a spatial grid or a society of independently learning citizens. The election receives a supplied calibration ranking and a scripted probability of selecting its best candidate. The mandate-commitment ablation is useful within that supplied design; it is not evidence of emergent democratic competence.

The new release records exact source hashes and source snapshots, complete configs, all calibration/evaluation seed rows, full evaluation event/message histories, and seed-paired uncertainty intervals. Its protocol was written before the pilot. It remains exploratory because prior results informed the model and experiment selection, and the24 evaluation seeds per scenario form a bounded pilot rather than a powered generalization study.

References: [SciPy's permutation design documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html) distinguishes independent and paired sample permutations; [Watkins and Dayan (1992)](https://www.gatsby.ucl.ac.uk/~dayan/papers/cjch.pdf) states the setting and conditions of the standard Q-learning convergence result.
