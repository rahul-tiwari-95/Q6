# Research preview validation — 6 September 2026

The preview adds a visible-rule adaptation kernel, two preserved pilots, separate post-hoc reference policies, a calibrated provenance comparison, and a viewer in the existing dashboard. These checks establish implementation and artifact integrity; both adaptation pilots still fail their initial-competence gate.

## Local test coverage

All **290 currently collected cases** are covered by passing runs, rather than one uninterrupted full-suite invocation:

| Execution | Result | Scope |
| --- | --- | --- |
| Integrated fast lane | 282 passed, 3 deselected; 46.16 seconds | Entire then-current suite except the three named slow cases |
| Follow-up after the replay-capacity guard | 14 passed; 286.51 seconds | All 11 current learning tests, including five new invalid-configuration cases, plus the three previously deselected cases |

The three slow cases are the five-episode legacy self-play smoke and the two floored-decay learning checks documented in [CONTRIBUTING](../../CONTRIBUTING.md#tests). Both executions seeded Python, NumPy and Torch with zero and set one Torch CPU thread. The follow-up reran the affected learning tests after the guard changed; no pilot was retrained.

Separate focused checks included 39 provenance tests and 28 orchestrator tests. The provenance verification recomputed all 288 saved evaluation losses and matched 12 full policy/scenario replays exactly; see [the machine-readable verification](../experiments/provenance-verification.json).

## Supported installation and CI

The first published implementation revision, `9eafa4e`, passed [GitHub CI](https://github.com/rahul-tiwari-95/Q6/actions/runs/34011134597): **287 passed, 3 deselected** on both Python 3.10 and 3.12. The Python 3.12 job built the distributions, installed the wheel into an isolated target, and imported the runtime modules away from the source tree. The full lane is scheduled/manual; the push/PR lane intentionally excludes the three long cases.

Subsequent work adds the artifact-integrity command to CI, dashboard syntax validation, and documentation clarifications. Consult [the pull request checks](https://github.com/rahul-tiwari-95/Q6/pull/1/checks) for the final revision's status.

The saved numerical pilots and local tests used the pre-existing **Python 3.9.6** environment, with Torch 2.8.0 and NumPy 2.0.2, recorded in their metadata. The new installable package supports **Python 3.10+**; the quickstart explicitly uses Python 3.12. Passing installation tests on newer interpreters does not establish bit-identical numerical reproduction across environments. [Relevant local versions](2026-09-06-environment.json) were captured after the pilots and are not a complete dependency lock.

## Evidence and dashboard checks

`python scripts/verify_pilot_artifacts.py` verifies both original adaptation protocol/source snapshots, all 14 aggregate groups per pilot against their raw evaluation CSVs, and all 26 files in the provenance SHA-256 manifest. The archived source is deliberately preserved even when current code receives a later API guard. CSV line endings are preserved through Git attributes so artifact hashes survive checkout.

`node --check --input-type=module < dashboard/lab.js` passes. Native Chrome review covered:

- Latest pilot load and the prominent failed-competence interpretation.
- Shortest-path reference selection and playback to a completed two-step trajectory.
- Switching from a reference back to the after-B continuing learner.
- Both experiment tabs, archived v1 selection, and the corresponding numerical results.
- Changing provenance from the default distribution to rarer reports/later shift, with updated bars, intervals and paired differences.
- Desktop rendering of both tracks, including visible rule mappings and clear units.

The viewer shows saved observations, not a live training session. Dashboard document links serve the repository's Markdown artifacts; a browser may download these files. The legacy registry remains available but is explicitly marked historical because many original raw run files are absent from a fresh checkout.

## Owner decisions and next boundary

The owner chose to show the active rule and leave the license undecided. This is a research preview. The next training milestone is a separately specified A-only competence diagnosis; there was no third adaptation tuning run. Memory architectures remain deferred until the basic learner is competent enough for a meaningful retention comparison.
